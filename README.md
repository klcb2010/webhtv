# WebHTV · 个性化增强版

本项目基于鱼壳进行二次开发，并借鉴墨壳的部分功能设计与实现，持续完善手机端和 TV 端的使用体验。

<p align="center">

  <a href="https://github.com/klcb2010/webhtv/tree/main">精简版（main）</a>


  
  <a href="https://github.com/klcb2010/webhtv/tree/MPV">完整版（MPV）</a>
</p>

> [!IMPORTANT]
> **分支说明**
> - **main：精简版**，使用 EXO 播放器方案。
> - **MPV：完整版**，包含 MPV 播放器及相关功能。
>
> 两个分支拥有独立的升级逻辑，请根据自己的使用需求选择。

> [!WARNING]
> **WebView 加载注意事项**
>
> 算法助手等 Hook 工具可能拦截 WebView 或其网络请求，导致 HTML 页面无法加载、直播播放失败。遇到相关问题时，请检查此类工具的拦截规则。

## 项目说明

本项目以鱼壳为基础，在保留原有架构的基础上进行个性化定制与功能增强，同时参考墨壳的部分功能设计和实现。

- **兼容性：** 覆盖手机端与 TV 端，部分功能按设备类型提供。
- **播放器：** 精简版以 EXO 为主，完整版提供 MPV 方案。
- **本地化：** PG 兼容本项目，采用纯本地化方式，不拉闸，推荐作为主 Jar。
- **喜欢本项目：** 欢迎点击仓库右上角的 ☆ **Star** 支持项目。

## 功能一览

### 首页与导航

- 首页最近观看（TV 端）
- 默认加载点播（TV 端）
- 锁定首页源（TV 端）
- 首页推送开关（新增手机端）
- 首页功能按钮调序
- 启动进入直播（双端）
- 直播默认全屏（双端）

### 搜索、历史与播放

- 搜索线程
- 搜索结果排序优先（双端）
- 全局历史
- 分集进度
- 全屏播放返回详情
- 豆瓣海报与个性推荐直达播放（需 Jar 本身支持，例如东篱、clun、肥猫、南风）
- 播放直达网盘优先
- 网盘搜索播放推送
- 迅雷、射手字幕
- AI 豆瓣推荐

### 播放器与字幕

- 播放器设置更多隐藏开关（双端）
- EXO 及 MPV 解码下的字幕颜色与内置字体（双端）
- 内封字幕优先中文（双端）
- 楷体字幕自动放大（双端）
- E-AC3 音频软解（双端），尝试改善部分设备因音频解码能力不足造成的 4K 音频卡顿
- 精简版使用 EXO 截图，完整版使用 MPV 截图（仅手机端）
- 播放界面透明后底栏（TV 端）
- HTML 站点全屏按钮（TV 端）

### 直播与 WebView

- WebView 直播支持
  - 功能参考：[llb0/webhtv](https://github.com/llb0/webhtv)
  - 注意：算法助手、LSP 一类 Hook 工具可能拦截 WebView 网络请求，导致播放失败。
- EPG 地址：[pp.xml](https://raw.githubusercontent.com/sparkssssssssss/epg/main/pp.xml)

### 系统与个性化

- 自动备份开关
- 退出确认（新增手机端）
- 真退出（新增双端）
- 家长控制（新增双端，重启生效）
- 自动检测更新（新增双端）
- 更多内置镜像加速（新增双端）
- 退出自动清理缓存（新增双端）
- 关于界面细节优化（新增双端）

> 注：原有“自动换源”功能已隐藏。上游播放设置中已经自带该功能，因此不再作为本项目的独立 Mod 项目。
